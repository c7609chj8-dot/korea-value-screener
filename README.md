# korea-value-screener

한국 주식의 연간 실적·가치 지표를 CSV로 분석하는 Next.js 16 앱입니다. 공식 API 연동과 인증키 설정 없이 사용합니다.

## 실행

Node 20.9 이상에서 `npm ci`, `npm run dev`. 검증은 `npm test`, `npm run build`.

## 현재 동작 범위

- 검증된 형식의 재무 CSV 업로드, 지표 계산, 전략 프리셋, 조건 필터와 정렬
- 최대 4종목 비교, 관심종목·검색 조건·투자 가설 메모의 브라우저 저장
- CSV 내보내기, 결측값·기저효과·현금흐름·가격 기준일 경고

실제 전체 시장 데이터, 자동 시세 갱신, AI 분석은 아직 연결되지 않았습니다. 기본 상태는 실제 데이터가 없는 빈 화면입니다. 가상 데이터는 사용자가 기능 체험을 선택할 때만 표시합니다.

## 데이터 양식

데이터 연결 화면에서 빈 양식과 가상 예제를 내려받을 수 있습니다. UTF-8 CSV, 최대 5MB/5,000종목. code는 앞자리 0을 보존한 6자리 문자열입니다. 가격은 원, 재무 금액 및 시가총액은 억원입니다. capex는 유형·무형자산 취득 현금지출의 양수 합계입니다.

연간 연결 기준으로 netIncome은 지배주주 순이익, equity/previousEquity는 지배주주 지분입니다. liabilities는 연결 부채총계입니다. 부채/지배주주 지분은 일반적 부채총계/총자본 지표와 다릅니다. period는 2025-FY 같은 형식이고 asOf는 가격 기준일입니다. source에는 출처 및 재무 공시일을 기록하세요. 공시 직전·직후 데이터를 섞지 마세요. 분기 데이터와 TTM은 현재 지원하지 않습니다.

업로드는 서버로 전송하지 않습니다. 브라우저 저장소를 지우면 관심종목·메모·데이터가 삭제됩니다. 기기 간 동기화는 없습니다. 데이터 내보내기는 종목 및 재무 데이터만 포함합니다.

## Vercel

Framework: Next.js / Node: 22.x 또는 24.x / Build: npm run build. 앱용 API 인증키와 환경변수는 필요하지 않습니다. 로그인 및 프로젝트 연결 후 배포할 수 있습니다.

기존 CSV의 corpCode 열은 더 이상 필요하지 않습니다. 기존 양식은 추가 열이 있어도 업로드할 수 있으며, 새 내보내기에서는 이 열을 제외합니다. 브라우저에 저장된 기존 데이터도 현재 양식으로 변환합니다.

발굴 점수는 수익성 35 / 매출 성장 25 / 가격 25 / 현금 15의 휴리스틱입니다. 수익률로 검증된 전략이나 매수 추천이 아닙니다. 자세한 수식은 앱의 평가 기준에서 확인하세요.
